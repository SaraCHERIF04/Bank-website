Banking Web Application

A full-stack banking web application developed during my internship at BADR Bank. The app allows users to manage their accounts, perform transactions, and handle credit card details securely. Built with React.js for the frontend, Flask (Python) for the backend, and MySQL for database management.

Key Features:

User authentication & profile management
Account and transaction handling
Credit card management
Agency integration
Tech Stack: React.js | Flask | MySQL | JavaScript | CSS
